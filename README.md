# Ayrik_Matemetik_hafta_2

🚀 Ayrık Yapılar | 2. Hafta Ödevi

Bu hafta Ayrık Yapılar dersinde Boole Fonksiyonları ve Mantık Devreleri konusunu işledik ve haftalık ödevimizi tamamladık!

 Çalışma boyunca; 

• Mantık ifadelerini sadeleştirme ve doğruluk tabloları oluşturma 

• Mantıksal kapılarla devre tasarımı yapma 

• İfadelerin De Morgan ilkeleriyle dönüşümünü sağlama üzerine pratik yapma fırsatı buldum.
